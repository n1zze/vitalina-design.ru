# Task01 Services Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Обновить каталог и шесть страниц услуг по `task01.md`, сохранив текущий дизайн статического сайта.

**Architecture:** Изменения выполняются непосредственно в существующих HTML-страницах и общем CSS без внедрения шаблонизатора или новых зависимостей. Две новые страницы повторяют структуру действующих страниц услуг, а проверочный Node-скрипт валидирует обязательный контент, порядок карточек, ссылки и локальные ресурсы.

**Tech Stack:** HTML5, CSS3, существующий JavaScript сайта, Node.js для статических проверок.

## Global Constraints

- Не выполнять общую переработку CSS и не менять визуальный ритм существующих страниц.
- Не добавлять внешние зависимости.
- Не удалять и не откатывать существующие изменения рабочего дерева.
- Сохранить все текущие изменения для итогового snapshot-коммита.
- Использовать цены, сроки, названия и состав услуг из `task01.md`.
