## 1. Контекст и цель

Сайт — статичный (HTML+CSS+JS), переживает ребрендинг SAPAROVA → VITALINA DESIGN. Страница
«Контакты» (`portfolio/contact.html`) структурно уже свежая (hero, контакт-строки, форма),
но стили живут в легаси-скине `skins/saparova/css/main.css` (9031 строка).

Цель — **редизайн страницы контактов в строгом «бюро»-минимализме** (по референсу
fantalis.ru/contacts) с добавлением **сплит-блока «карта + контакты»** (по пожеланию заказчика,
блок на манер aleart-design.ru/contacts), сохранив **фирменную тёплую палитру** остальных
страниц портфолио.

Направление (утв. заказчиком): «строгий бюро»; структура — две колонки контактов; карта —
сплит-блок с картой Краснодара; email добавлен. **Астрахань не используется** — работа ведётся
по г. Краснодар и Краснодарскому краю.

## 3. Структура страницы (по вертикали)

1. **Hero** — крупный H1 «Контакты», подзаголовок: «Работаю в Краснодаре и Краснодарском
   крае, удалённо — по всей России. Самый быстрый способ связи — Telegram».
2. **Сплит-блок «Карта + контакты»** (ключевая фишка):
   - Left: встроенная Яндекс.Карта (Краснодар) на всю высоту блока.
   - Right: белая карточка с контактами, разбитыми на **две колонки**:
     - **«Обсудить проект»** → телефон, email, Telegram, MAX.
     - **«Для клиентов»** → личный кабинет CRM, часы работы.
3. **Форма** «Давайте обсудим ваш проект» — имя + телефон (маска) + согласие на обработку
   ПД; валидация и success-блок (существующий JS переносится без изменений).
4. **Футер** — существующий (копирайт 2025 © vitalina-design.ru, code-bureau.ru).

Плавающая кнопка-чаёк (`.mfb-`) и соцсети в шапке — вне задачи, остаются как есть.

## 4. Визуальный язык (фирменная тёплая палитра)

- **Фон:** тёплый крем `#f8f5f0` (секции), белые карточки `#fff`.
- **Текст:** графит `#1a1714`; вторичный `#8a7e74` / `#6b6560` (labels, hints).
- **Акцент:** фирменная терракота `#c99471` (ссылки `contact-row__link`, фокус-состояния),
  hover `#b5835f`.
- **Разделители строк:** `1px solid #e8e4df`.
- **Форма:** рамки инпутов `#e8e4df`, фокус `#c99471`, ошибка `#c0392b`, success `#27ae60`.
- **Типографика:** Inter/Manrope (уже подключены); H1 `tracking-tight`, `leading-none`,
  размер `clamp(2.5rem→4rem)`; labels капсом, мелкие, с трекингом; значения крупно `weight 500`.
- **Воздух:** вертикальные отступы секций `clamp(64→120px)`.

## 5. Раскладка

- **Сплит-блок «Карта + контакты»** — сетка из 2 колонок на десктопе:
  - **Колонка 1 (карта):** встроенная Яндекс.Карта (Краснодар) на всю высоту колонки. Никаких
    других городов — только Краснодар.
  - **Колонка 2 (карточка контактов):** белая карточка, внутри — внутренняя сетка из 2
    под-колонок «Обсудить проект» / «Для клиентов» (на десктопе рядом, на узких экранах
    стекаются друг под друга).
- **Мобильный:** весь сплит-блок стекается в 1 колонку — карта сверху, карточка снизу;
  под-колонки внутри карточки также в столбик.
- Обёртка `max-width ≈ 1200px`, центрируется.

## 6. Организация CSS (рефакторинг)

- Стили страницы контактов **выносим** из `skins/saparova/css/main.css` в отдельный
  `skins/saparova/css/contact.css`.
- В `contact.html` подключается после `main.css` (чтобы не ломать остальные страницы
  портфолио).
- Общие стили (header, footer, `.mfb-`) остаются в скине.
- Классы — префикс `contact-` (уже частично есть): `contact-map`, `contact-card`,
  `contact-row`, `contact-form` и т.д.

## 7. Поведение / анимация

- Существующие reveal-анимации на `IntersectionObserver` (с `prefers-reduced-motion`) —
  сохраняются.
- JS формы (маска телефона, валидация, success) — переносится без изменений.
- Никаких тяжёлых анимаций; мягкое появление секций.
